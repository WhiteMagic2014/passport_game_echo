# 回声 ECHO

> 一部运行在 FoloToy AI Passport（ESP32-C3）上的电梯恐怖生存游戏。
> 240×320 ST7789P3 屏幕，三个按钮，没有声音提示以外的任何引导。

---

## 背景

你在一部电梯里醒来。

不记得自己什么时候进来的，不记得按了哪一层。显示屏上的数字是 **B0**——地面层。门关着，轿厢里只有顶灯嗡嗡地响。

你试探着按了向下。电梯动了。

井道里的风声越来越大，数字一格一格往下跳。B1，B2，B3……你开始觉得不对劲——这栋楼到底有多深？你住的那栋楼，有地下停车场，但不会深成这样。

电梯在某层停住了。门没开。

你听见井道深处有什么东西在动。

---

## 玩法

### 基本操作

| 按键 | 作用 |
|------|------|
| ↑ / ↓ | 升降一层 |
| OK（短按） | 打开控制面板 |
| OK（长按） | 关闭面板 |

### 控制面板

打开面板后有四个选项：

- **呼喊** —— 向井道发出声音，通过声呐回波判断门外的情况。但声音会引来注意。
- **聆听** —— 安静地贴门听。能大致判断它的方位，但给不出精确层数。
- **开门** —— 打开电梯门，拿外面的东西。不可逆。
- **返回** —— 关闭面板。

### 四项数值

| 图标 | 含义 |
|------|------|
| 食 | 食物。归零后开始掉血。移动、呼喊、开门都会消耗。 |
| 命 | 生命。遭遇它时会大幅扣减。归零即结束。 |
| 智 | 理智。越低，回声越不可信。归零也会结束。 |
| 碎 | 碎片。散落在某些楼层里，需要开门才能找到。 |

### 声呐

呼喊后，声波从电梯向外扩散。回波会勾勒出门外的轮廓——空的楼层、堆满杂物的、有配电设施的，以及其他东西。

如果回波荡出了**双圈**，那是它在回应你。

### 磨损

每次升降和开门都会磨损电梯。磨损到一定程度，电梯会停摆。

### 它

井道里不止你一个。你听不到它的脚步，但它听得见你的声音。

你越呼喊，它越近。

## 技术参数

- **平台**：ESP32-C3，FoloToy AI Passport
- **屏幕**：240×320 ST7789P3，RGB565
- **渲染**：分带双缓冲（BAND_H=40），无 PSRAM 全帧渲染
- **音效**：预生成 PCM 嵌入 flash（~1.1MB），运行时流式播放，仅占 1KB DRAM
- **存档**：NVS 持久化最深记录与上局呼喊足迹
- **分区**：factory 3MB / recovery 1MB / cardid 16KB

## 编译

```bash
# 需要 ESP-IDF v5.x
idf.py set-target esp32c3
idf.py build
idf.py flash
```

## 项目结构

```
main/
  echo_core.c/h    游戏逻辑状态机（纯 C，不依赖 BSP）
  echo_render.c/h  像素渲染层（分带绘制、字库、声呐、UI）
  echo_audio.c/h   音频任务（flash PCM 流式播放）
  echo_main.c      主程序（BSP 初始化、主循环、按键、存档）
  font_zh.h         中文字库（851 个字符，16×16 点阵）
  sfx_data/         预生成音效 raw PCM
components/bsp/     板级支持包（显示、按键、音频、I2C）
tools/gen_sfx.c    音效生成器（PC 端编译运行）
```
